# 癌症认知框架

## 核心定义 #肿瘤学

**癌症**是一类由自身细胞失控（基因突变）引起的疾病——体内的某个正常细胞在累积了关键基因错误后，不再听从身体的"停止生长"指令，开始无节制地分裂、扩散，最终侵占正常器官的空间和营养。

> **类比**：你的身体是一座由 37 万亿"居民"（细胞）组成的超级城市。每个居民手里都有一本完全相同的城市法规（你的 DNA）。每隔一段时间会有居民抄错法规，通常会被城市警察（免疫系统）当场纠正或清除。但偶尔，某个居民连续抄错了足够多关键条款，警察没发现，于是这个居民开始搞违章建筑、偷城市水电（抢夺营养）、甚至派子代渗透到其他街区（转移）——这就是癌症。

## 领域分类

```
癌症
├── 按组织来源（大类）
│   ├── 癌 → 来自上皮组织（皮肤、器官表面、腺体），占 80-90%
│   │   ├── 腺癌 → 乳腺、肺、结肠、前列腺
│   │   └── 鳞状细胞癌 → 皮肤、食道、宫颈
│   ├── 肉瘤 → 来自骨、软骨、脂肪、肌肉等结缔组织
│   ├── 白血病 → 血液细胞，在骨髓中产生
│   ├── 淋巴瘤 → 淋巴系统（免疫系统盟友叛变）
│   └── 神经系统肿瘤 → 脑、脊髓
├── 按生物学特征
│   ├── 实体瘤 vs 液体瘤 → 有形肿块 vs 在血液/淋巴中漂浮
│   ├── 良性 vs 恶性 → 不扩散 vs 侵入周围组织并转移
│   └── 分期（Stage I-IV） → 肿瘤大小、淋巴结受累、远处转移
├── 按驱动机制（Hallmarks）
│   ├── 持续增殖信号 → 细胞不断接到"分裂！"的假指令
│   ├── 逃避生长抑制（抑癌基因） → 刹车踏板被卸掉
│   ├── 抵抗细胞死亡 → 该自杀时不自杀
│   ├── 无限复制能力 → 端粒酶让细胞"不老不死"
│   ├── 诱导血管生成 → 肿瘤自己建高速公路抢营养
│   └── 激活侵袭和转移 → 细胞学会"坐地铁"到处跑
└── 按病因
    ├── 遗传性 → 先天携带关键基因突变
    ├── 环境性 → 吸烟、紫外线、化学物、病毒
    └── 偶发性 → "运气不好"，细胞分裂时随机复制错误
```

## 常见误区

1. ❌误区："癌症是绝症，得了就等于判死刑"
✅正解：癌症不是一种病，是几百种不同的病。早期乳腺癌的 5 年生存率超过 90%，儿童急性淋巴细胞白血病治愈率超过 85%。但胰腺癌、小细胞肺癌等确实仍然凶险。正确的问题是"我的癌症是哪种，在什么分期"，而不是"得了癌症还能活多久"。
💡原因：癌症在文化叙事中被塑造成单一的"不治之症"，这种简化的恐惧比复杂的事实更容易传播。

2. ❌误区："酸性体质导致癌症""糖喂养癌细胞所以要断糖"
✅正解：人体的酸碱度由精密调控系统严格维持（pH 7.35-7.45），不存在"酸性体质"。癌细胞确实消耗更多糖（Warburg 效应），但正常细胞也依赖糖。全身断糖先饿死的是你自己（特别是脑细胞），而非选择性地饿死癌细胞。
💡原因：基于真实科学发现的扭曲——Warburg 效应（1931 年诺贝尔奖）是真实存在的生物化学现象，但被简化为"所以不吃糖就能饿死癌细胞"。这忽略了癌细胞代谢的灵活性：它们可以切换燃料。

3. ❌误区："活检会让癌细胞扩散"——这是最危险的误区之一
✅正解：现代穿刺活检的针道转移风险极低（低于 0.01%），且活检是确诊和分型的关键步骤。因为害怕这个微小风险而拒绝活检、延误确诊的风险大几个数量级。
💡原因：历史上粗针活检确实有少量案例报告，但被口口相传放大成"开刀会让癌细胞扩散"的民间信念。

4. ❌误区："癌症只要切干净就没事了"
✅正解：癌细胞在原发性肿瘤还很小时，就可能已经通过血液和淋巴系统悄悄扩散，这些"微转移灶"在影像学上不可见。所谓"切干净了"指的是肉眼和显微镜下切缘阴性——不等于体内一个癌细胞都没有了。
💡原因：外科手术的"可见成功"给人虚假的安全感，人们难以理解微观层面的不确定性。

## 底层原理

1. **癌症是基因突变的累积过程（多步致癌）**：一个正常细胞变成癌细胞，通常需要 2-8 个关键基因的突变累积。这就是为什么癌症与年龄高度相关——突变需要时间积累。这也是为什么单一"修复一个基因"难以治愈大多数癌症。

2. **原癌基因与抑癌基因——汽车加速与刹车**：原癌基因像油门踏板，突变后"卡住了"持续告诉细胞分裂。抑癌基因像刹车，突变后刹车踏板被卸掉。两者同时出问题时，细胞的分裂控制系统彻底崩溃。

3. **Hallmarks（癌症的十大特征）**：Hanahan & Weinberg 在 2000/2011/2022 年定义了癌症必须获得的特性——不仅是"无限增殖"，还包括"逃避生长抑制""抵抗细胞死亡""无限复制""诱导血管生成""激活侵袭和转移""重新编程能量代谢""逃避免疫系统""基因组不稳定""促癌炎症"。这些不是并列的"特征列表"，而是一个"系统工程"——肿瘤在进化过程中按顺序解锁这些能力。

4. **肿瘤微环境（TME）——肿瘤不是孤岛**：癌细胞不是孤立行动的。它们招募正常细胞（成纤维细胞、免疫细胞、血管细胞）来形成一个"支持性生态系统"。这个"微环境"提供生长因子、抑制免疫攻击、建立物理屏障。理解 TME 是当下癌症研究的核心战场。

5. **免疫编辑——免疫系统和癌症的三轮博弈**：第一阶段：免疫系统清除大部分癌细胞（消除）。第二阶段：免疫压力筛选出能伪装的癌细胞（平衡）。第三阶段：癌细胞进化出完整的免疫逃逸能力（逃逸）。免疫检查点抑制剂的作用就是打破第三阶段的封锁，重新激活免疫系统。

## 最新前沿

1. **CAR-T 与细胞治疗**
   - 从患者体内取出 T 细胞（免疫战士），基因改造后装上一个"癌细胞识别雷达"（嵌合抗原受体），回输体内。在血液系统肿瘤中取得了革命性效果
   - 来源：June et al., *Science*, 2018; FDA 已批准多个 CAR-T 产品（Kymriah, Yescarta 等）
   - 瓶颈：对实体瘤效果有限，细胞因子释放综合征（CRS）的毒性管理，成本极高（> $400,000/次）

2. **免疫检查点抑制剂（PD-1/PD-L1/CTLA-4）**
   - 原理：癌细胞利用 PD-L1 蛋白对 T 细胞喊"我是自己人，别攻击"。PD-1 抑制剂阻断这个信号，让免疫系统重新识别和攻击癌细胞
   - 来源：James Allison（CTLA-4）和 Tasuku Honjo（PD-1）获 2018 年诺贝尔生理学或医学奖
   - 争议：只有 20-40% 的患者响应，预测"谁会响应"仍是巨大挑战

3. **液体活检（ctDNA 检测）**
   - 抽一管血就能检测肿瘤释放到血液中的游离 DNA 片段，实现无创早筛和复发监测
   - 来源：*Science*, 2017, "Liquid Biopsy" 专刊; Illumina/Grail 公司的 Galleri 检测
   - 瓶颈：早期癌症的 ctDNA 含量极低，伪阳/伪阴性的"不确定性区间"在临床上如何沟通

4. **mRNA 癌症疫苗**
   - COVID-19 mRNA 疫苗的成功推动了癌症治疗性 mRNA 疫苗的发展——针对每个患者肿瘤的独特突变谱"定制"疫苗
   - 来源：Moderna/Merck 的 mRNA-4157 在黑色素瘤 III 期试验中取得积极结果（2023）
   - 争议：个性化疫苗的生产周期（数周）能否赶上肿瘤进展速度？成本能否降到可及？

5. **AI 在癌症影像学诊断中的应用**
   - 深度学习在乳腺癌钼靶筛查中达到或超过放射科医生水平
   - 来源：*Nature*, 2020, McKinney et al., "International evaluation of an AI system for breast cancer screening"
   - 争议：AI 模型的"黑箱"问题——如果 AI 发现了医生看不到的模式但它自己不向 AI 也有解释，这个发现在临床上是否值得信任？

## 核心难题

1. **转移——90% 癌症死亡的直接原因**：原发肿瘤可以通过手术根治，但一旦癌细胞扩散到远处器官，全身治疗的有效性急剧下降。我们仍不完全理解"为什么某个癌细胞决定离开原发灶""为什么它选择肺/肝/骨/脑而不是其他地方"。

2. **耐药性——进化在你眼皮底下实时发生**：肿瘤是在患者体内持续进化的细胞群体。化疗/靶向药/免疫治疗施加的选择压力，会让耐药细胞亚群从几近灭绝中反弹。这不是"药物失效"，是肿瘤进化出了绕行路线。

3. **肿瘤异质性——同一个肿瘤里没有两个完全相同的癌细胞**：同一患者同一肿瘤的不同区域、甚至同一区域的相邻细胞，其基因突变谱、表达谱都不同。这解释了为什么一个靶向药只能清除部分癌细胞——因为这些细胞在基因层面已经是"不同的病"。

4. **早期检测的特异性难题**：筛查的目的不是"找到所有癌症"，而是"在黄金窗口期内找到真正需要干预的癌症"。过度诊断会导致不必要的手术和焦虑。PSA 筛查争议（前列腺癌）和甲状腺癌的"过度诊断流行病"是典型案例。

5. **胰腺癌和胶质母细胞瘤——依然几乎不可治疗**：尽管免疫治疗和靶向治疗在黑色素瘤、非小细胞肺癌等取得了重大进展，胰腺癌和胶质母细胞瘤的中位生存期几乎没有改变。为什么？胰腺癌的高纤维化基质形成物理屏障阻止药物渗透；胶质母细胞瘤受血脑屏障保护且具有高度侵袭性。（*CA: A Cancer Journal for Clinicians*, 2023 统计）

## 跨领域连接

- **[[进化生物学]]**：肿瘤内部的克隆演化和耐药性——达尔文自然选择在患者体内微观尺度实时上演
- **[[免疫学]]**：免疫监视与免疫逃逸——癌症本质上是免疫系统的"情报失败"
- **[[基因组学]]**：全基因组测序揭示的突变图谱、突变特征（smoking signature/UV signature/APOBEC signature）
- **[[衰老]]**：癌症与衰老共享多个分子通路（端粒缩短、基因组不稳定），理解衰老有助于理解癌症
- **[[数据科学]]**：TCGA/PCAWG 等大规模癌症基因组项目需要先进的统计和计算方法来提取信号

## 现实映射

1. **体检筛查决策**：癌症筛查的好处和风险并存。PSA 筛查（前列腺癌）可能导致过度诊断——找到了一些"永远不会进展到威胁生命的惰性癌症"但患者仍然接受了手术。在做任何筛查前，先了解该检查的过度诊断率和假阳性率。

2. **治疗选择中的"总生存期 vs 无进展生存期"**：当医生汇报"新药的中位无进展生存期比旧药多 3 个月"时，追问——这 3 个月的生活质量如何？总生存期有差异吗？有些药物延缓了影像学上的进展（肿瘤在 CT 上没变大），但并没有实际延长生命。

3. **临床研究信息解读**：看到"治愈率提高 50%"的标题时，问清楚这是绝对风险降低还是相对风险降低。相对风险降低 50% 可能是从"100 人中 2 人患癌"降到"100 人中 1 人"，绝对风险仅降了 1%。

4. **家族史≠命运**：即使你的家人患过癌症，大多数癌症不是纯粹遗传的。BRCA1/2 突变真正导致乳腺癌、卵巢癌高风险，但它们只占所有乳腺癌的 5-10%。对大多数人来说，生活方式（吸烟、饮食、运动）的影响远大于遗传。

5. **与医生沟通的框架**：确诊后，用 TNM（分期）→ 分子分型 → 治疗选项（手术/放疗/化疗/靶向/免疫）→ 每项的总生存获益和生活质量影响 → 基因检测是否有指导意义，这个顺序依次提问。

### 决策检查清单

1. 在病历或笔记本上写下：癌症的组织学类型、TNM 分期、分子分型（如 EGFR/ALK/BRAF 等驱动基因状态）——缺哪项就去问医生补齐哪项。
2. 拿出治疗方案说明，圈出疗效指标是"中位生存期延长"还是"5 年生存率提高"，在旁边注明这两个指标分别意味着什么（前者看中位线，后者看尾部）。
3. 用计算器算一遍：绝对风险降低了多少？相对风险降低了多少？把两个数字并列写下来，不要只看大的那个。
4. 列一份"生活质量影响清单"：化疗的恶心天数、手术后的功能损失、日常活动受限程度——逐项写出来，和生存获益放在同一页纸上对比。
5. 打开 uptodate 或 cancer.gov，查出该癌种该分期的自然病程（不治疗情况下的典型进展时间和结局），写下来作为决策基线。
6. 把当前这个信息的来源写下来：是 PubMed 上检索到的 RCT 论文 → 可信度高；还是病友群/朋友圈转发的文章 → 可信度低；标出来源类型再决定放多大权重。
7. 拿出一张纸，写下"如果不治疗，我还有多少有质量的时间？"——把这个数字和治疗可能额外争取的时间并列，问自己：多出来的这段时间，我想用来做什么？
8. 有没有一种替代假设也能很好地解释我当前的状况？比如：这个症状有没有可能是良性病变而非癌症？这个治疗效果好，有没有可能只是自然病程的波动而不是药效？把它写下来，至少列出一个竞争性解释。
