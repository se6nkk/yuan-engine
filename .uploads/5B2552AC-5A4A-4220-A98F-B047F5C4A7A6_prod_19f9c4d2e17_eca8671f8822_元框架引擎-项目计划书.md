# 元框架引擎 — 项目计划书

> 创建日期：2026-07-26
> 状态：方向确认，待细化验证

---

## 1. 一句话定义

输入任意概念，输出一套结构化认知框架——含定义、分类、发展脉络、前沿进展、核心难题、渐进学习路径。

它不是维基百科，不是 ChatGPT 问答，不是思维导图工具。它是**给你一张认知地图**。

---

## 2. 为什么做

### 2.1 用户痛点

- 学新概念时碎片化——Google 给出 10 个链接，但没有一个告诉你"怎么看这个领域"
- ChatGPT 给线性回答——问一句答一句，不会主动帮你建立体系
- 维基百科给术语堆砌——你能读完，但读完后仍然不知道从哪里开始学
- 思维导图工具需要你自己想结构——你不知道这个领域的结构是什么
- 没人做"**从一个词出发，建一座认知大厦**"

### 2.2 竞品空白（已验证）

| 类型 | 代表产品 | 做什么 | 与我们的区别 |
|------|----------|--------|------------|
| AI 思维导图 | Mapify.so | 从 PDF/视频提取要点生成导图 | 从已有内容压缩，不是从概念出发 |
| 知识图谱 | ai-knowledge-graph | 从文档提取实体-关系三元组 | 关系抽取，不生成认知框架 |
| 手动脑图 | XMind / Miro | 你画图它辅助 | 纯手工 |
| AI 问答 | ChatGPT / Claude | 一问一答 | 线性回答，不主动建体系 |

**空白确认：当前无直接竞品。**

## 3. 核心产出物（一个概念框架的标准结构）

输入一个词（如"数学"），输出以下模块：

| # | 模块 | 说明 |
|---|------|------|
| 1 | 核心定义 | 这个概念的本质是什么，用一句话讲清楚 |
| 2 | 领域分类 | 完整的分类树，每个分支一句话解释 |
| 3 | 发展脉络 | 关键节点时间线，知道这个领域怎么来的 |
| 4 | 底层原理 | 支撑整个领域的几条核心公理/原理 |
| 5 | 最新前沿 | 当前最活跃的研究方向/争议/突破 |
| 6 | 核心难题 | 这个领域最难的问题，为什么难 |
| 7 | 学习路径 | 从入门到精通的渐进式学习路线图 |
| 8 | 关键概念索引 | 必须掌握的 20-50 个核心概念清单 |
| 9 | 与其他领域的交叉 | 和哪些领域有深层联系，怎么连起来的 |
| 10 | 实用价值映射 | 这个概念能解决什么实际问题 |

## 4. 产品形态（暂定两阶段）

### 阶段一：内容验证（当前）
不做代码，用精调 prompt + LLM 手动生成 10 个概念框架，发布到社交媒体验证用户需求。
- 目标：生成 10 篇，观察反馈
- 检验指标：是否有 3 篇以上获得显著互动
- 周期：2 周

### 阶段二：MVP 工具
做一个极简 Web 工具：输入框 → 生成按钮 → 结构化渲染。

| 组件 | 技术方案 |
|------|----------|
| 框架生成 | LLM API（Claude/GPT）+ 精调 system prompt |
| 输出格式 | LLM 返回结构化 JSON → 前端渲染为可折叠层级视图 |
| 前端 | 单页 HTML，类似 Notion 大纲风格 |
| 扩展 | 可选：对生成的框架调用五虎上将做批判性审视 |
| 附加 | 一键导出 Markdown / 图片 |

## 5. 差异化武器

- **从概念出发，不是从文档出发**——竞品都是在压缩已有内容
- **结构化不是装饰，是本质**——输出是一张可导航的地图
- **内置批判层（五虎）**——不只是生成框架，还可以审视框架
- **可跨场景**——学习 / 创作 / 投研 / 决策 都能用

## 7. 核心风险与应对

| 风险 | 严重程度 | 应对 |
|------|----------|------|
| LLM 幻觉（编造不存在的分类/历史） | 高 | 加领域知识验证层；标注"AI 生成，供参考" |
| 框架一致性（同概念两次生成结构不同） | 中 | 固化 prompt 模板 + 输出 schema 约束 |
| 用户付费意愿不足 | 高 | 先做内容验证，不花钱试需求 |
| 大厂复制（Claude/GPT 原生支持类似功能） | 中 | 差异化在框架设计哲学 + 五虎审视层，这是 prompt 工程壁垒 |
| 概念范围无限广，质量难统一 | 低 | 先聚焦高价值垂直领域（学习方法/投资/科技）做模板优化 |
