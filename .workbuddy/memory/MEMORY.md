# 元引擎 · 项目长期记忆

## 产品核心原则（用户明确决策，2026-07-30）
1. **绝不让用户看到错误信息**：人大脑对错误认知极其顽固（用户举例：就像把 "safari" 错记成别的、很久刷不掉）。因此校验必须在**生成/展示之前**完成，用户最终只看到已校对的正确内容。
2. **校验流程**：生成词条时即开始事实级校验（L2，逐条断言比对权威来源）。
   - 能确认正确的 → 直接显示正确内容（静默修正，不让用户看到错误版本）。
   - 不确定的 / 找不到原文出处的 → 显示 ⚠️ 标记，注明"AI 自行生成，未找到出处，仅供参考"。
3. **轻量级体验，最少决策**：产品交互尽量少让用户做选择/决策。错误不该伪装成对的，但也不该把判断负担丢给用户——只把"无法确认"的项显式标注即可。
4. 当前实现的"来源验证"面板是 **L1 概念级**（只查 topic 是否存在），**无法发现年份/人名等事实级错误**，属于已知缺口，需升级到 L2。
