# 交接说明：脑图字号问题

## 症状
脑图 SVG 中的文字字号偏大，改了多次（SVG font-size 属性、CSS em、固定 px 值）都不生效或反而更大。

## 根因（已确认）
**SVG viewBox 缩放导致文字被放大。**

SVG 的 `font-size` 是 SVG 用户单位（viewBox 坐标），不是屏幕像素。当 SVG 通过 `max-width: 100%` 被拉伸到容器宽度时，所有内容（包括文字）等比放大。

举例：
- viewBox = `0 0 400 300`
- 容器宽度 = 800px
- SVG 被放大 2 倍
- `font-size: 11px`（SVG 属性）→ 屏幕上显示为 22px

## 尝试过的方案（均未解决）
1. SVG `font-size` 属性设固定 px → 被 viewBox 缩放放大
2. CSS class + em → 继承的 em 也被缩放
3. CSS `font-size: 11px` on SVG root → 仍然被 viewBox 缩放
4. `width: auto` → 某些浏览器当作 100% 处理
5. 去掉 `width` → SVG 按 viewBox 自然尺寸渲染，但容器宽时仍可能被 `max-width` 拉伸

## 正确修法（建议）
**方案 A：SVG 不缩放（最简单）**
```css
.module-mindmap .module-content svg {
  display: block;
  width: 100%;       /* 填满容器 */
  height: auto;
  font-size: 11px;   /* 但这不起作用，因为 viewBox 缩放 */
}
```
不行，需要用 `vector-effect: non-scaling-stroke` 的思路，但 SVG text 没有等价属性。

**方案 B：用 HTML 文字替代 SVG text（推荐）**
- SVG 只画线条和圆点
- 文字用 `<foreignObject>` 或绝对定位的 `<div>` 覆盖在 SVG 上
- 文字用 CSS px/em，不受 viewBox 缩放影响

**方案 C：计算缩放比，反向补偿 font-size（可行但复杂）**
```js
// 在 SVG 插入 DOM 后，读取实际渲染宽度
const svgEl = document.querySelector('.module-mindmap svg');
const renderedWidth = svgEl.getBoundingClientRect().width;
const viewBoxWidth = svgEl.viewBox.baseVal.width;
const scale = renderedWidth / viewBoxWidth;
// 反向补偿：如果缩放了 2 倍，font-size 设为 11/2 = 5.5
const actualFs = 11 / scale;
svgEl.querySelectorAll('text').forEach(t => {
  t.setAttribute('font-size', actualFs);
});
```

**方案 D：不用 viewBox（最暴力的修法）**
- 去掉 viewBox，SVG 用实际像素坐标
- `width` 和 `height` 设为计算出的像素值
- `font-size` 就是屏幕像素，1:1
