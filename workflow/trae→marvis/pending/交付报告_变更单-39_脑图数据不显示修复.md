# 交付报告：变更单-39 脑图数据不显示修复

## 修复内容

### 问题
领域分类模块显示"暂无分类数据"，脑图无法渲染。

### 根因
1. System prompt 中领域分类模块没有格式约束，LLM 输出格式随机
2. 解析器 `parseMindmapCategories` 五种策略都要求"类别+列表项"结构，无法处理纯段落文本

### 三处修改

| # | 位置 | 修改 |
|---|------|------|
| 1 | `buildSystemPrompt` 领域分类模块（~521行） | 增加格式要求：加粗标题+列表项，附示例 |
| 2 | `CACHE_VERSION`（494行） | v4 → v5，旧缓存自动失效 |
| 3 | `parseMindmapCategories` 末尾（~1390行） | 增加解析6兜底：纯文本按行分割，每行作为独立分类 |

### 工作原理
- 新生成的框架：LLM 按格式约束输出，解析器1（bold标题+列表项）直接命中
- 旧缓存：版本不匹配自动失效，重新生成
- 极端兜底：即使 LLM 输出纯段落，解析6也能把每行拆成分类
