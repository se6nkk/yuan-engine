- **文件**：`index.html`

#### 2a. 新增版本常量
- **位置**：L467
- **代码**：`const CACHE_VERSION = 'v2'; // v1=四层, v2=五层`

#### 2b. 缓存命中版本检查
- **位置**：L780-791
- **逻辑**：`dbGet` 命中后比对 `cached._cacheVersion !== CACHE_VERSION`
  - 版本不匹配 → 旧缓存失效，不 return，继续走搜索 + LLM 生成流程
  - 版本匹配 → 正常渲染缓存，秒开

#### 2c. 保存时写入版本号
- **位置**：L822
- **代码**：`dbPut` 时附带 `_cacheVersion: CACHE_VERSION`

## 验收步骤
1. 用旧概念（已有四层缓存）重新生成 → 版本不匹配，走重新生成 → 五层正确显示
2. 生成完成后再次输入同一概念 → 缓存命中（v2标记），秒开
3. 进度条在 LLM 调用前显示「AI 正在生成认知框架（预计 10-20 秒）...」
4. 清空 IndexedDB 后首次生成 → 正常生成，保存带 v2 标记

## 技术说明
- 旧缓存数据不会被删除，只是版本不匹配时被跳过（走重新生成覆盖）
- `generateSub` 中的 `dbGet` 不做版本检查（子框架无层级结构问题）
- 版本号存储在 IndexedDB 记录的 `_cacheVersion` 字段中
