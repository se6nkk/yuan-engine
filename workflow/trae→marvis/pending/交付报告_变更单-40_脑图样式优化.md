# 交付报告：变更单-40 脑图样式优化

## 四项修改

| # | 需求 | 实现 |
|---|------|------|
| 1 | 字体太大 | 二级三级 = bodyFs（正文字号），一级 = bodyFs×1.15（稍大） |
| 2 | 端点从文字边缘出发 | 新增 `textWidth()` 函数精确估算文字宽度（中文1em/英文0.55em），线段起点 = 文字右边缘，终点 = 下一级文字左边缘 |
| 3 | 圆滑曲线无转折 | 替换 Z 形（L+C+L）为纯三次贝塞尔 `smoothPath()`，控制点在水平中点，形成 S 曲线 |
| 4 | 颜色区分线段 | 7 色调色板，每个二级分支一个颜色，线段+端点圆点统一使用分支色 |

## 额外优化
- X 坐标改为动态计算（基于文字宽度 + 列间距），不再硬编码 320/180/20
- SVG 宽度更紧凑，消除右侧空白
- 线段 opacity 从 0.3 提到 0.5，端点圆点从 0.3 提到 0.6
