# 变更单-18 v3：时间轴事件→Wikidata 逆向校验（事件匹配法）— 交付报告

## 执行状态：已完成

## 变更概述

时间轴中的每条事件，提取关键实体（人名 / 关键名词），用英文搜索 Wikidata。命中实体后读取其日期属性（P569、P571、P585、P793 等），与时间轴宣称年份比对。结果以折叠 `<details>` 呈现在 SVG 下方，默认收起。

## 适配说明

变更单原文引用 `static/js/app.js` 和 `static/css/style.css`，实际项目为单文件 `index.html`，所有 JS/CSS 内联。已做以下适配：
- 选择器保持 `.tl-verify-loading`（不改为 `.meta-timeline-svg`）
- `AbortSignal.timeout(4000)` 替换为 `AbortController + setTimeout(4000)` 模式
- `appendVerifyPanel` 改为设置容器 div 的 innerHTML（不创建新元素追加到父节点）
- `parseTimelineEvents` 分隔符兼容 `：/:/- /—`，年字段支持 `YYYY年` 和 `YYYY` 两种写法
- 渲染输出使用 `esc()` 转义防止 XSS

## 五级校验说明

| 标记 | 级别 | 含义 | 颜色 |
|------|------|------|------|
| ✓ | true | 年份完全匹配 Wikidata 实体日期 | 绿色 #22c55e |
| ~ | close | 年份接近（±2 年） | 黄色 #eab308 |
| ⚠ | mismatch | 实体存在但年份不符 | 红色 #ef4444 |
| ? | partial | 实体存在但无日期属性 | 灰色 #a0a0a0 |
| - | false | 未匹配到 Wikidata 实体 | 无色 |

## 交互流程

1. 用户搜索概念 → 进入阅读器 → 时间轴模块
2. **SVG 时间轴**：正常渲染，无任何额外标记
3. **异步校验**（页面加载后立即触发）：
   - 提取每条事件中的实体（中文人名 / 英文大写词 / 引号内名词）
   - 用英文搜索 Wikidata（每个实体最多搜 3 个，每个实体最多查 2 条）
   - 读取命中实体的日期属性，与宣称年份比对
4. **折叠面板**：SVG 下方出现带边框的折叠条，概要显示「交叉校验 N 项：X 项通过验证 · Y 项年份存疑 ...」
5. **展开后**：每条事件按五级显示，附 Wikidata 实体链接
6. **断网/超时**：不出现校验面板，SVG 保持原样
