# WB 交付：误区对照重设计 — 交付报告

## 执行状态：已完成

## 变更概述

将「常见误区」模块从**左右分栏卡片堆叠**重设计为 WB 确认的**误区置顶 + 正解·洞察并排**布局。认知逻辑：误区仅作「被纠正对象」单独置顶，不与正解并排，避免读者把错误和正确一起锚进记忆。

| 6 | 清理旧 CSS 类名残留 | ✅ |

## 旧 vs 新 对照

| 维度 | 旧版 | 新版（WB 设计） |
|------|------|----------------|
| 误区位置 | 左栏卡片（与正解并排） | 全宽置顶一行 |
| 正解位置 | 右栏卡片 | 下方左栏（宽 60%） |
| 洞察位置 | 最下方全宽卡片 | 下方右栏（窄 34%） |
| 背景 | 三色卡片（红/绿/蓝底） | 无底色 |
| 圆角 | 8px | 无 |
| 标签 | ❌ 错误认知 / ✅ 正确理解 / 💡 深层洞察 | ✗ 误区 / ✓ 正解 / • 洞察 |
| 标记颜色 | 红/绿/蓝 | 玫红 #993556 / 青绿 #0F6E56 / 灰 #888780 |
| 分隔 | 卡片间距 | 1px 淡灰横线 + 1px 淡灰竖线 |

## 交互流程

1. 用户搜索概念 → 进入阅读器 → 常见误区模块
2. **误区置顶**：每组第一条全宽显示 `✗ 误区：……`
3. **淡灰横线分隔**
4. **正解（左宽栏）** + **洞察（右窄栏）** 并排，中间细竖线分隔
5. 多组依次堆叠，组间距 1.6rem
6. 断网/解析失败 → 回退到 `marked.parse` 纯文本渲染
