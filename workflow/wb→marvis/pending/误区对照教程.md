# 误区对照图（误区置顶 / 正解 · 洞察并排）教程

适用场景：把「常见误区 vs 正确理解」这类对照内容，画成比卡片堆叠更轻、且**不容易让读者记住错误**的极简图。

---

## 1. 认知逻辑（为什么这么排）

- **误区单独置顶一行**：它只是「被纠正的对象」，不和正解并排，避免左右对照时读者的视线把「错误」和「正确」一起锚进记忆。
- **正解 + 洞察并排在下**：这对组合才是要留下的记忆锚点——正解纠正误区，洞察给一个更高层的原理。
- 所以阅读节奏是：看到误区 → 往下看正解把误区覆盖 → 旁边配洞察加深。

## 2. 视觉结构

```
┌─────────────────────────────────────────────┐
│ ✗ 误区：……（一行，置顶，全宽）               │
├─────────────────────────────────────────────┤   ← 淡线分隔
│ ✔ 正解：……（左，较宽）   │ • 洞察：……（右，较窄）│
└─────────────────────────────────────────────┘
        （重复 N 组）
```

- 误区：全宽置顶，下方一条淡灰横线分隔。
- 正解：下方左栏，较宽（占约 60%）。
- 洞察：下方右栏，较窄（占约 34%），中间一条细竖线分隔。
- 无标题、无卡片、无底色。

## 3. 关键技术约束（WorkBuddy Visualizer · 必读）

> 这套图是用内置 Visualizer 的 `show_widget` + diagram 模块画的内联 SVG。**有一个坑必须知道**：

- ⚠️ **`widget_code` 只能有 1 个根 `<svg>` 元素。**
  - 纯 HTML 模式：禁止内嵌 `<svg>`。
  - SVG 模式：禁止再嵌套 `<svg>`（即不能用 `<svg>` 画小图标）。
- ✅ **要自然换行，正确姿势 = 单个根 `<svg>` + `<foreignObject>` 包 HTML 文本流。**
  - `<foreignObject>` 里放标准 HTML（`<div style="...">`），CSS 会自动折行，不用手动断句。
  - HTML 里的 `xmlns="http://www.w3.org/1999/xhtml"` 不能省。
- ✅ **标记符号用文字，不用图标**：`✗`（玫红）/ `✓`（青绿）/ `•`（灰），靠 `color` 着色。不要用内联 svg 画叉勾。
- ❌ 禁用：渐变、阴影、模糊、emoji、旋转文字、小于 11px 的字。
- 字号只用两级权重：`400` 常规 / `500` 中粗（不要 600/700）。

## 5. 复现步骤（以 680 宽画布为例）

1. 根 svg：`viewBox="0 0 680 750"`、`width="100%"`、`font-family="-apple-system, system-ui, sans-serif"`。
2. 每组占 180px 高，4 组起点 y = `10 / 190 / 370 / 550`。
3. 误区 `<foreignObject>`：`x=44 y=组y width=592 height=52`，HTML 里 `✗ + 误区文字`。
4. 横向分隔线：`<line x1="44" y1="组y+58" x2="636" y2="组y+58" stroke="#ededea"/>`。
5. 正解 `<foreignObject>`：`x=44 y=组y+64 width=368 height=104`，`✓ + 正解文字`。
6. 洞察 `<foreignObject>`：`x=430 y=组y+64 width=206 height=104`，`• + 洞察文字`。
7. 竖向分隔线：`x=420`，`y1=组y+66` → `y2=组y+158`，`stroke="#e3e1da"`。
8. 文字过长时**不要手动断行**——`<foreignObject>` 里的 HTML 会自动按 `width` 折行。

> 想改栏宽：保持 `44 + 正解宽 ≈ 412`、`竖线在 420`、`洞察 x=430`、二者之和 `≤ 636` 即可。

## 6. 一句话适配清单

- [ ] 单根 `<svg>`，用 `<foreignObject>` 包 HTML 做自然换行

- [ ] 无标题、无卡片、无底色；分隔线只用 1px 浅灰
- [ ] 字号两级（14/13）、字重两级（400/500）
