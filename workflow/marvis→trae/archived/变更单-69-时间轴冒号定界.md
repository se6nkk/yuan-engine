# 变更单-69：时间轴解析根治——冒号定界

**日期**：2026-07-29

## 问题
`parseTimelineItems` 的 `.+?[：:\-—]` 非贪婪匹配导致年份错断（如 `1960年：1970年：xxx` 拆分混乱），加上 `trailingYearMatch` 对事件内容二次抽年份，进一步污染 date。

## 修复

### 1. 解析逻辑（index.html 约第2063行 `parseTimelineItems`）

将：
```javascript
const match = plain.match(/^(.+?)[：:\-—]\s*(.+)/);
if (match) {
  let date = match[1].trim();
  let event = match[2].trim();
  const trailingYearMatch = event.match(/^(\d{4})[：:\-—]/);
  if (trailingYearMatch) {
    date = date + '-' + trailingYearMatch[1];
    event = event.replace(/^\d{4}[：:\-—]\s*/, '');
  }
  items.push({ date, event });
}
```

改为：
```javascript
const match = plain.match(/^(.+?)(：|:)\s*(.+)/);
if (match) {
  items.push({ date: match[1].trim(), event: match[3].trim() });
}
```

即：只用冒号定界，删除 trailingYearMatch 二次抽年份逻辑。

### 2. Prompt 格式约束

在 `/Users/sean/Documents/元引擎/prompts/system_prompt_v3.0.md` 中，发展脉络部分的格式约束必须明确定界规则：

> 时间轴每行格式：`年份/年段：事件描述`（冒号分隔，冒号前为完整日期标签，冒号后为事件描述，禁止在事件描述中再夹带日期标签）

## 影响
仅影响时间轴解析，不涉及其他模块。
