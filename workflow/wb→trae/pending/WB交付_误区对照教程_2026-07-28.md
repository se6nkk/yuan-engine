## Visualizer 关键约束（抄作业时必看）
- `widget_code` 只能有 **1 个根 `<svg>`**。
- 自然换行：单根 `<svg>` + `<foreignObject>` 包 HTML 文本流，**不要手动断行**。
- 标记用文字符号 `✗ / ✓ / •` 着色，**禁止内嵌 `<svg>` 画图标**。
- 字号两级（14 / 13）、字重两级（400 / 500）；禁 emoji / 渐变 / 阴影。
